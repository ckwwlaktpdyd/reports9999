# reports9999

한국 주식 투자 참고용 리서치 브리핑을 모으는 저장소입니다.

이 저장소의 목표는 초보자에서 중급 투자자까지 읽을 수 있는 한국어 브리핑을 꾸준히 쌓는 것입니다. 매수나 매도를 지시하기보다, 시장 맥락과 확인해야 할 근거를 정리해 투자 판단 과정을 돕는 데 초점을 둡니다.

## 구조

- `program.md`: 자동화 에이전트가 따를 운영 지침
- `prompts/korean-stock-briefing.md`: 브리핑 작성 프롬프트
- `reports/`: 날짜별 브리핑 저장 위치
- `reports/index.md`: 작성된 브리핑 목록

## 리포트 원칙

1. 출처 링크가 있는 최신 사실과 해석을 구분합니다.
2. 종목은 관심 후보로만 다루며, 개인화된 투자 조언이나 직접적인 매수/매도 지시는 하지 않습니다.
3. 상승 요인뿐 아니라 리스크, 실적, 밸류에이션, 확인할 지표를 함께 적습니다.
4. 초보자도 이해할 수 있게 전문 용어는 짧게 풀어 설명합니다.
5. 마지막에는 투자 공부에 도움이 되는 짧은 교육 메모를 덧붙입니다.
